# Samaytrix Backend

This is the Node.js/Express backend for Samaytrix, a school management system.

## Deviations from Master Spec
* **Science and IT Lab Exemption (Grades 1-8)**: As per the initial testing of the Timetable Engine, the physical constraints of having only 2 science/computer labs makes it mathematically impossible to satisfy lab requirements for all grades simultaneously. To solve this, Science and IT for Grades 1-8 have been exempted from the lab requirement and are taught in standard classrooms. Lab capacity is strictly reserved for the Grade 9-10 stream subjects (Physics, Chemistry, Biology, Computer Science).
